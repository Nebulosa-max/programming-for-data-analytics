# Programming for Data Analytics – Coursework

This repository contains coursework completed as part of the Programming for Data Analytics module.

## Repository Structure

- `assessment/`  
  Final assessment project analysing historical wind speed data using Python.

- `assignments/`  
  Weekly assignments submitted during the semester.

- `my-work/`  
  Practice exercises, labs, and exploratory work completed during the module.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Git & GitHub

## Notes
Each section of the repository reflects progressive learning throughout the semester, culminating in the final assessment project.
